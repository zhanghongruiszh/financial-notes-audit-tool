# 测试项目放这里

把要测试的项目文件直接丢进这个文件夹，一个项目一个子文件夹即可。

## 每个项目需要三个文件

|文件|常见命名|说明|
|-|-|-|
|审计报告附注|`3、审计报告附注-XX-两年一期.doc`|Word，要有「财务报表主要项目附注」章|
|审计报告报表|`2、审计报告报表-XX-两年一期.xlsx`|资产负债表 / 利润表 / 现金流量表|
|TB 试算平衡表|`TB-试算平衡表（新）-XX.xls`|要有现金流量表|

命名不用改，程序会自己从文件名里推项目名（`XX`），输出目录叫
`XXcheck\\\_v1`、`XXcheck\\\_v2`…（同一项目再跑就自动加版本号）。

`.doc` / `.xls` 也能直接用，程序会先转成 `.docx` / `.xlsx`；
如果你手上已经有 `.docx` / `.xlsx`，直接放这两种更省事（不经过 Office，快很多）。

## 目录示例

```
test/
├─ 项目A/
│   ├─ 3、审计报告附注-项目A-两年一期.doc
│   ├─ 2、审计报告报表-项目A-两年一期.xlsx
│   └─ TB-试算平衡表-项目A.xls
├─ 项目B/
│   └─ ...
└─ 2024年度/
    └─ ...
```

## 跑完看什么

1. `汇总表` → 二、差异明细（有「定位」链接，点一下跳到勾稽底稿）
2. `完整性` → 未披露 / 附注号 / 跨表 / 尾随负号
3. `勾稽底稿` → 与 Word 版式一致，勾稽行紧贴目标行下方，右侧是报表数与差额
