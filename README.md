# 财务报表附注自动化勾稽与编号治理系统 (Audit-Notes-Check)

> 一套专为财务审计、IPO申报、国企及上市公司报表复核打造的自动化勾稽与附注编号治理系统。

---

## 🌟 核心特性与审计业务逻辑

### 1. 附注编号全自动闭环治理
* **Word 附注拓扑自检**：自动扫描《主要项目附注》与《母公司主要项目附注》，识别断号（跳号）、重号与乱序。
* **双重锚点识别**：不仅支持阿拉伯数字识别，还内嵌 80+ 个标准会计科目语义库。对于未打编号的子科目，绝不漏抓。
* **Word 附注一键重排**：一键将附注子项目按文档物理顺序重新规范编排为连续的 `1、`、`2、`、`3、` ... $N$。
* **报表主表附注号一键回填**：智能读取附注章节前缀（如 `六、`），自动补全报表主表（资产负债表、利润表、现金流量表）空白的附注列，或纠正错位编号。

### 2. 报表对外披露第一原则
* **法定对外报表 ↔ 附注合计数公式勾稽**：主表项目与附注合计数直连公式校验（`=报表!E7 - 附注!B11`），差异高亮。
* **单体公司 vs 合并集团双轨自适应**：
  * **单体公司**：仅核对单体报表与附注；
  * **合并集团**：自动开启“合并附注 ↔ 合并报表”与“母公司附注（应收/其他应收/长投/收入成本/投资收益） ↔ 母公司报表”双轨核对。

### 3. TB 现金流量表补充资料逐格核对
* **底稿深层明细闭环**：针对报表主表未展开但附注详细披露的现金流量表补充资料（净利润调节项、现金及等价物变动、银行存款构成等），与 TB 底稿（`CF-Indirect` / `CF-Direct` 审定数 `A.A`）进行 1 对 1 逐格校验。

### 4. 自动归档与版本控制
* 每次勾稽自动创建公司专属二级文件夹（如 `铁联化轻/`）。
* 输出成果严格遵循 `附注check_项目名_v1.xlsx` 命名规范，再次运行自动递增为 `v2`、`v3`，历史版本全部永久保留。

## 🚀 快速启动指南

### 方式一：免安装绿色版运行（推荐）
直接双击运行本项目根目录下的独立可执行文件：
```text
财务报表附注自动化勾稽系统.exe
```
无需安装 Python 环境，任何 Windows 电脑均可直接打开使用。

### 方式二：Python 源码运行
依赖环境：Python 3.8+，需安装相关依赖：
```bash
pip install openpyxl pywin32
python audit_check_app.py
```

```text
├── audit_check_app.py           # 桌面图形交互应用 (GUI)
├── audit_check_engine.py        # 核心勾稽引擎 (加减算法/双轨匹配/TB核对)

├── word_to_excel_extractor.py   # Word 表格抽取转换器
├── 财务报表附注自动化勾稽工作流与复用操作指南.md  # 详细业务操作与复用手册
├── 财务报表附注自动化勾稽系统.exe # 单一独立执行文件
└── .gitignore                   # 严格排除所有业务数据与底稿文件 (100%防泄密)
```
