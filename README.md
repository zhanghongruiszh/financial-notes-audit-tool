# 财务报表审计附注核对工具 (Financial Notes Audit Tool)

财务报表审计附注核对工具是一套面向注册会计师、审计项目组及企业财务复核人员的自动化核对与附注编号治理系统。系统覆盖从 Word 格式审计报告附注、Excel 格式财务报表主表到 TB 试算平衡表底稿的全链路自动化核对。

* 项目主页：https://github.com/zhanghongruiszh/financial-notes-audit-tool
* 问题反馈与交流：henryzhang825@gmail.com

## 核心功能

### 1. 附注子项目编号治理
* **编号拓扑自检**：自动扫描附注主要项目章节，精准识别跳号、断号、重号及乱序问题。
* **会计科目语义识别**：内置会计准则标准会计科目库。若段落未标注序号（如遗漏编号），系统依然通过科目语义与文档层级进行捕获，避免漏项。
* **Word 附注一键规范重编号**：限定在主要项目附注（及合并报表下的母公司主要项目附注）范围内，按文档物理出现顺序依次重新编号为规范的连续序号，不破坏原有排版与格式。
* **报表主表附注号一键回填**：识别附注大标题中文字符（如“六、”或“五、”），自动将资产负债表、利润表、现金流量表等主表缺失的附注列补齐，或对错位编号进行批量更正。

### 2. 报表与附注法定对外披露一致性核对
* **合计数公式直连勾稽**：报表主表项目金额与附注各披露小节的合计数建立直接公式核对，差异实时高亮。
* **单体与合并双轨自适应**：
  * 单体公司：仅执行单体报表与附注的一对一核对；
  * 合并集团：自动执行“合并报表主要项目 ↔ 合并报表主表”与“母公司报表主要项目 ↔ 母公司报表主表”双轨独立核对。

### 3. TB 现金流量表补充资料逐格核对
* 对外报表未单独展开但附注详细披露的现金流量表补充资料（间接法净利润调节明细、现金及现金等价物净变动、银行存款明细、受限资产等），与 TB 底稿现金流量表审定数（A.A 列）进行逐单元格核对。

### 4. 自动归档与版本控制
* 每次勾稽自动建立项目专用归档子文件夹，归档所有提交的原始文件。
* 结果文件统一命名为 `附注check_项目名_v1.xlsx`。若后续更新数据重新执行，版本号自动递增（v2, v3...），历史版本全部完整保留。

## 使用方式

### 方式一：免安装可执行程序（推荐）
直接运行根目录下的独立可执行程序：
```text
财务报表附注自动化勾稽系统.exe
```
无需配置 Python 环境，可在 Windows 64 位系统直接运行。

### 方式二：Python 源码运行
运行环境要求：Python 3.8 及以上。
依赖库：
```bash
pip install openpyxl pywin32
```
启动主界面：
```bash
python audit_check_app.py
```

## 数据保密声明

本仓库通过 `.gitignore` 严格排除所有原始业务数据及生成底稿（包括所有 `.xlsx`、`.xls`、`.doc`、`.docx` 格式文件及企业子目录），任何实际项目底稿均仅留存于本地，不上传至代码仓库。
